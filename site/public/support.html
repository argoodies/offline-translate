QW! Privacy Support

Support

QW! 0.1.0 for iPhone and iPad.

Getting a reply

Tap the page and start writing. There is no send button — putting the keyboard away is what commits the paragraph. Two things do that: tapping the blank space below the cursor, or tapping the checkmark in the top right. The answer begins on the next line.

Tapping between paragraphs you have already written just moves the cursor; it will not send anything.

The first launch takes a few seconds

Half a gigabyte of model weights has to be mapped into memory before anything can run. The progress bar is paced on a timer rather than on the engine's own figures, which arrive unevenly and then stop entirely for the last stretch. Later launches are faster because the file is already warm.

Replies are slow

Speed depends almost entirely on the chip. On recent iPhones the model runs at conversational speed; on older devices it is noticeably slower, and there is no server to offload to. Shorter conversations also help — every reply re-reads the context above it.

A thin line appeared at the top

That is the context window filling up. The model can only hold so much of a conversation at once. When the line is full, the oldest exchanges start being dropped to make room. Starting a new note gives you a clean window.

The app has no words in it

That is deliberate. The only word on screen is QW!, and that is the product name. Everything else is a shape, so the app does not have to pick a language. The one place this costs you something: renaming a note and deleting all notes were removed, because both need a dialog with Cancel and OK buttons. Notes take their title from the first line, and you can delete one by swiping it left in the list.

The answer is wrong

It is a 0.8-billion-parameter model — small enough to fit on a phone, and correspondingly limited. It will get facts wrong, especially about recent events, and it has no way to look anything up. Treat replies as a starting point, not a source.

Where my notes are

On the device, inside the app's private storage. They are not synced anywhere and not included in any account. Deleting the app deletes them permanently. See the privacy policy.

Report a problem

Email argoodies@googlegroups.com, or open an issue at github.com/argoodies/qw/issues. Useful things to include: device model, iOS version, and what you were writing when it happened.

The source is at github.com/argoodies/qw if you would rather read the code than the description.
