QW! Privacy Support

Privacy

QW! collects nothing. There is no server to collect it to.

The short version

QW! makes no network requests. Not for the model, not for analytics, not for crash reports, not for checking whether an update exists. The app contains no networking code at all, which means this is not a promise about how data is handled — it is a statement that there is no path for data to leave.

You can verify it yourself: turn on Airplane Mode and use the app normally. Nothing degrades, because nothing was ever being fetched.

What is collected

Personal information (name, email, phone)None
Account or sign-inNone — there is no account
Your notes and the model's repliesStay on the device
Usage analytics or telemetryNone
Crash reportsNone
Advertising or tracking identifiersNone
LocationNever requested
Contacts, photos, microphone, cameraNever requested
Third-party SDKsNone
CookiesNone — the app has no web content

This corresponds to Data Not Collected on the App Store privacy label.

Where your notes live

Notes are written to a single file inside the app's own container on the device. Only QW! can read it — iOS keeps that container private.

They are not synced to iCloud and are excluded from nothing in particular — they simply never leave the app's storage. Deleting QW! deletes them along with it, and there is no copy anywhere else to recover them from.

The model

Qwen3.5‑0.8B is bundled inside the app package. It is loaded from local storage and run locally on the device's GPU through Metal. Your prompts are turned into tokens in memory and never serialised anywhere except the notes file you can see.

The model's weights are fixed. Nothing you write trains it, adjusts it, or is retained by it between launches.

Read aloud

Long-pressing a reply can read it aloud using AVSpeechSynthesizer, the system speech engine. It uses voices already installed on your device and runs offline. QW! does not send the text anywhere to have it spoken.

If you have not downloaded a voice for a given language, iOS may offer to fetch one. That download is between you and Apple; QW! is not involved and does not require it.

Sharing and copying

If you tap Share or Copy on a reply, the text goes wherever you send it, and that destination's privacy terms take over from there. That is the only way content leaves the app, and it only happens when you ask for it.

Children

QW! is not directed at children and collects no data from anyone, including children. Replies come from a language model and are not filtered or reviewed; treat them the way you would treat any generated text.

Changes

If a future version ever collects anything, this page will say so before that version ships, and the App Store privacy label will change to match. Given that the app has no networking code, such a change would be a rewrite rather than a tweak.
